1. Overview

The Affiliation filter lets users narrow Search and Browse results by UC Davis organizational unit. Departments are organized in a three-level hierarchy: Category → Sub-category → Department.

The filter is available on both the Search page (filtering across all result types) and the Browse by Experts / Grants / Works pages (filtering the displayed roster). Behavior differs slightly between desktop and mobile, and between Search and Browse.

2. Data source

The organization hierarchy is maintained in a Google Sheet and compiled into a static JavaScript module consumed by the front-end bundle.

Google Sheet

URL stored in config.google.orgLookupSheetUrl (commons config), overridable via the ORG_LOOKUP_SHEET_URL environment variable.

Default: https://docs.google.com/spreadsheets/d/1vTqlpEI9vyzeZG2TTTNNFFXgC7u7OqI5wkY47TOohZM/export?format=csv&gid=647977625

Sheet column mapping

Sheet column Maps to Notes
AE Filter CategoryTop-level category labelRows with no value are skipped
AE Filter Sub CategorySub-category labelRows with no value are skipped
Suggested Display Namedepts[].nameUser-facing department name
Official Namedepts[].officialNameUsed for matching against HR/ES data
Dept Codedepts[].deptCodeES filter value sent to the API
Order in the sheet does not matter. The CLI sorts all three levels alphabetically when writing the output file, so display order is determined by the front-end sort, not row order.

3. Data structure

The compiled output is an ES module exporting ORG_LOOKUP — an array of category objects, each with nested sub-categories and departments.

ORG_LOOKUP // Array
└─ { label: "Colleges" } // category
└─ subCategories // Array
└─ { label: "Agricultural and Environmental Sciences" }
└─ depts // Array
└─ { name: "Animal Science",
officialName: "ANIMAL SCIENCE",
deptCode: "30045" }

The deptCode values are sent to Elasticsearch as filter terms. When a user selects a sub-category checkbox (desktop) or drills into a sub-category and checks departments (mobile), the corresponding codes are added to the active filter set stored in the URL query string as the dept parameter.

4. UI — desktop

On screens wider than 767 px the Affiliation filter renders in the left sidebar. Behavior is identical on Search and Browse.

Search page
  • Sidebar always visible alongside results
  • Affiliation section is collapsible (caret toggle)
  • Search box filters the department list in real time
  • Sub-category rows have an expand/collapse caret
  • Sub-category checkbox = select all depts in that sub-category (indeterminate when partial)
  • Department checkboxes select individual depts
  • Active chips shown in .results-filtered-to row above results
Browse pages
  • Same sidebar layout as Search
  • Experts browse: Affiliation is the first (and only) filter group
  • Grants/Works browse: category selector (status / work type) appears above Affiliation in the sidebar
  • Selected dept codes are appended to the A–Z browse query
  • Active chips shown in .results-filtered-to row above the letter list

Checkbox states

Custom checkboxes (20 × 20 px) replace browser-native inputs to ensure consistent rendering. Three visual states are used:

  • Unchecked — white fill, 1px solid var(--ucd-blue-70) border
  • Checked — var(--ucd-blue-70) fill, white checkmark via ::after pseudo-element
  • Indeterminate — var(--ucd-blue-70) fill, white dash via ::after pseudo-element; set programmatically on sub-category checkboxes when only some child depts are selected

Alphabetical ordering

Categories, sub-categories, and departments are sorted alphabetically at construction time in the component constructor (using localeCompare), so display order is independent of the order in the source sheet.

5. UI — mobile

On screens 767 px wide and under the sidebar is hidden and replaced with a full-screen drawer system. The drawer is opened by tapping the Filter button.

Search mobile

1
Main drawer

Tapping Filter opens a full-screen overlay. The header reads "Refine Results" (italic). Filter sections — Affiliation, Date, Experts Open To — appear as rows with right-pointing carets.

2
Affiliation sub-drawer

Tapping Affiliation slides into a second full-screen view. A search box filters the list. Categories are rendered as group labels; sub-categories appear as tappable rows (no checkboxes at this level).

3
Department sub-drawer

Tapping a sub-category row opens a third view listing individual departments with checkboxes. Selecting a department immediately applies the filter.

4
Yellow "View N results" button

Pinned at the bottom of every drawer level. Label updates dynamically: "View N results" (All Results), "View N experts", "View N grants", "View N active grants", "View N journal articles", etc. Tapping closes the drawer.

Browse mobile

Browse mobile follows the same drawer pattern with two differences:

  • The drawer title is Filter (not "Refine Results") and there are no category options inside the drawer.
  • For Grants and Works browse, a category dropdown appears to the left of the Filter button (outside the drawer). It shows the current selection (e.g. "All Grants", "Active", "Journal Articles") with a chevron. Selecting an option calls the appropriate change handler and closes the dropdown immediately.
  • Experts browse has no category dropdown — only the Filter button.

Active filter chips (mobile)

Selected filters are shown as dismissible chips on the same row as the Filter button (and category dropdown if present). Each chip displays the filter label and an × that removes it. The chips wrap onto a second row if needed.

State properties controlling mobile drawer navigation:
mobileSubDrawer — null | 'affiliation' | 'openTo' | 'date'
mobileAffSub — null or the label of the currently open sub-category
mobileCategoryOpen — boolean (Browse only, controls the category dropdown)

6. Updating the org lookup table

Run the update-org-lookup CLI command whenever the Google Sheet is changed. The command fetches the sheet as CSV, converts it to the nested JSON structure, and overwrites org-lookup.js.

Running the command

# From the harvest/ directory
node bin/experts-admin.js update-org-lookup

# Preview without writing
node bin/experts-admin.js update-org-lookup --dry-run

# Write to a custom path
node bin/experts-admin.js update-org-lookup --output /path/to/org-lookup.js

# Use a different sheet URL
node bin/experts-admin.js update-org-lookup --url "https://docs.google.com/..."
1
Fetch

Downloads the sheet as CSV via the public export URL (follows Google's redirect automatically).

2
Parse

Parses CSV rows using csv-parse/sync with column headers. Rows missing AE Filter Category, AE Filter Sub Category, Suggested Display Name, or Dept Code are silently skipped.

3
Convert

Groups rows into the three-level hierarchy using Map objects keyed by category and sub-category labels. Insertion order is preserved from the sheet; the front-end sorts alphabetically at runtime.

4
Write

Serializes the array as export const ORG_LOOKUP = [...]; and writes it to the output path. The SPA must be rebuilt (webpack) for the change to take effect.

After running the command, rebuild the SPA bundle:
docker exec aggie-experts-spa-1 node_modules/.bin/webpack --config spa/client/webpack-watch.config.js

7. Key files

  • webapp/spa/client/public/lib/org-lookup.js Generated ES module — the compiled ORG_LOOKUP array. Do not edit by hand; regenerate with the CLI.
  • commons/lib/config.js Contains config.google.orgLookupSheetUrl — the Google Sheets CSV export URL.
  • harvest/bin/experts-admin.js CLI entry point. The update-org-lookup subcommand fetches and rebuilds org-lookup.js.
  • webapp/spa/client/public/elements/pages/search/app-search.js Search page component. Imports ORG_LOOKUP, sorts it in the constructor, manages mobileSubDrawer and mobileAffSub state, handles dept checkbox changes.
  • webapp/spa/client/public/elements/pages/search/app-search.tpl.js Search page template. Renders desktop sidebar affiliation tree and mobile sub-drawers.
  • webapp/spa/client/public/elements/pages/browse/app-browse-by.js Browse page component. Same ORG_LOOKUP import and drawer state, plus mobileCategoryOpen for the category dropdown.
  • webapp/spa/client/public/elements/pages/browse/app-browse-by.tpl.js Browse page template. Desktop sidebar, mobile category dropdown, and mobile filter drawer.
